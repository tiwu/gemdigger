# Plan - GitHub Pages Branch Deployment with Native Git

This plan outlines the changes to configure GitHub Pages deployments for both the `main` branch (production) and PR branches (previews) using native standard shell commands on the `gh-pages` branch, avoiding external third-party actions.

## Steps

1. **Create plan.md**
2. **Modify `.github/workflows/deploy.yml`**:
   - Update both `deploy-main` and `deploy-branch` to checkout the `gh-pages` branch using the official `actions/checkout` action.
   - Use standard `git` shell commands to copy built assets and commit/push them.
   - Ensure permissions are set to `contents: write` so the GITHUB_TOKEN can push changes.
3. **Run Linter**
4. **Update README.md**
5. **Move plan to ADR**
