# Plan - Exclude Dependabot from Branch Deploys

The goal is to prevent Dependabot from triggering branch deployments while still allowing it to run tests. Currently, the `deploy-branch` job runs on any `pull_request` where the head branch is not `main`.

## Proposed Changes

### GitHub Actions Workflow
- Update `.github/workflows/deploy.yml` to exclude branches starting with `dependabot/` from the `pull_request` trigger OR update the `deploy-branch` job condition.
- Updating the job condition is safer as it still allows tests to run on Dependabot PRs (which is desirable) but skips the deployment step.

## Implementation Steps
1. Create `plan.md` (this file)
2. Modify `.github/workflows/deploy.yml` to update the `deploy-branch` job condition to exclude `dependabot/` branches.
3. Run `npm run lint` to ensure no issues were introduced.
4. Update `README.md` to reflect that dependabot branches are excluded from auto-deployment.
5. Move `plan.md` to `./adr` with timestamp.
