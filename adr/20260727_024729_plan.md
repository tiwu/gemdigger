# Plan: UI Button Shortcuts & Changelog Merge

## Overview
Re-organize HUD buttons so they have logical shortcut keys, merge Changelog into Help, rename "Settings" to "Config", rename "Achievements" to "Badges", and ensure the app version is visible on the main screen and across these overlays.

## Key Changes
- `index.html`: Update HUD buttons with new ids/titles/hotkeys and order them (M, L, B, C, H). Merge `<div id="changelog-overlay">` contents into `<div id="tutorial-overlay">`. Rename overlay titles (Config, Badges). Add version spans for main screen and help screen.
- `src/js/main.js`: Update keydown bindings ('c' for config, 'b' for badges, remove changelog bindings). Map `__APP_VERSION__` to new version spans.
- `README.md`: Update Controls documentation to match the new hotkeys.

## Implementation Steps
1. Update `index.html`:
   - Change Settings toggle to have `data-hotkey="C"` and title Config.
   - Change Achievements toggle to have `data-hotkey="B"`, change text to Badges.
   - Re-order HUD buttons in DOM: Sound, Leaderboard, Badges, Config, Help.
   - Move the "What's New in v3.0.0" block from `#changelog-overlay` to `#tutorial-overlay`, placing it below the main rules list.
   - Remove `#changelog-overlay` entirely.
   - Add `<span id="help-version">0.0.0</span>` to the bottom of the `#tutorial-overlay`.
   - Add `<div id="main-version">v0.0.0</div>` to `#ui`.
2. Update `src/js/main.js`:
   - Delete `changelogOverlayEl`, `openChangelog`, `closeChangelog` and references.
   - Change 'c' keydown to call `openSettings()` / `closeSettings()`.
   - Add 'b' keydown to call `toggleAchievements()`.
   - Implement `toggleAchievements()` that checks `#achievements-overlay` display status and calls `renderAchievements()` when showing.
   - Inject `appVersion` into `document.getElementById('help-version')` and `document.getElementById('main-version')`.
3. Update `README.md`:
   - Remove "C: toggle Changelog"
   - Add "C: toggle Config (Settings)"
   - Add "B: toggle Badges (Achievements)"
4. Validate changes: run `npm run lint` and `npm run build`.

## Technical Considerations
- `appVersion` is already pulled from Vite via `__APP_VERSION__`, we just add more elements to populate.
- The UI spacing for the tutorial overlay might need adjusting so the "What's New" block fits nicely with existing rules.
- Test hotkey triggers to ensure they don't break when switching states.

## Success Criteria
- HUD buttons all show hotkey letters correctly.
- Pressing 'C' opens/closes Config screen.
- Pressing 'B' opens/closes Badges screen.
- Version numbers display properly at bottom-right on the main game view, and in Help/Config overlays.
- No trace of old standalone changelog (button, overlay) remains.
