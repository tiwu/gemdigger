### 1. Overview
The v3.0.0 update introduces the "Drill Wear" gameplay overhaul, emoji-based graphics, and vital UX improvements to improve player retention (Changelog, clearer tutorials). We are keeping the game 100% dependency-free using native Canvas rendering. Larger ideas (Multiplayer, Infinite Descent) are explicitly deferred to the `adr/features.md` roadmap.

### 2. Key Changes
- **UX & Input**: WASD movement, 'H'/'?' toggles for the help screen, in-game Changelog UI, much clearer new-player tutorial, increased toast visibility, and muting audio on window focus loss.
- **Drill Wear Update**: Introduce `BALANCE` object for central tuning. Shift fuel usage to per-tile costs (Empty: 0.2, Dirt: 1.0, Stone: 3.0, etc.). Update mining logic so drilling hard rock damages Hull if your Drill Power is too low.
- **Shop Expansion**: Introduce a new "Reinforced Bits" upgrade to mitigate drill wear.
- **Graphics**: Add procedural noise/speckling to Dirt/Stone, and replace the old shape-drawn gems with vibrant native Emojis (e.g., 💎) drawn directly to the canvas.
- **Roadmap Management**: Update `adr/features.md` to organize features into v3.0.0 (Current) and v3.1.0+ (Deferred).
