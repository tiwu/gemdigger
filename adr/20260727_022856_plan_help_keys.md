# Plan: Help Menu Keybindings & UI Hints

## Overview
The `h` and `?` keys (as well as `c` for changelog) are currently only functional when the Game Over overlay is visible. We will move these to a global scope, add proper toggling and closing logic (Escape/Enter), and introduce visual hotkey hints on the HUD buttons.

## Key Changes
- `src/js/main.js`: Refactor keydown listener for global hotkeys (`h`, `?`, `c`, `l`, `m`).
- `index.html`: Add `data-hotkey` attributes to HUD buttons.
- `src/css/base.css`: Add CSS for hotkey badges on HUD buttons.
- `README.md`: Document new hotkeys.
