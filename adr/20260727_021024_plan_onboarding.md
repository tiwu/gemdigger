# Plan: Onboarding & QoL Improvements

## Overview
Based on user feedback, gameplay mechanics are not always clear to new players. A static wall-of-text tutorial isn't enough. We will introduce contextual, event-driven hints that pop up during gameplay to guide the player exactly when they need it. Additionally, we will implement requested Quality of Life (QoL) improvements: increasing toast durations and adding a "Quit to Menu" option on the game over screen.

## Key Changes
- `adr/roadmap.md`: Update to include the "Onboarding & QoL Updates" in the Phase C release.
- `index.html`:
  - Add `#tutorial-hint` toast container for the dynamic hints.
  - Add a "Quit to Menu" button to the `#overlay` (game over screen).
- `src/js/tutorial.js`: New file to manage tutorial state, tracking seen hints and displaying new ones based on gameplay events (`start`, `gem_found`, `low_fuel`, `at_base`, `shop`, `hard_rock`).
- `src/js/main.js`:
  - Initialize the tutorial system and hook the "Quit to Menu" button to show the boot screen.
  - Dispatch `shop` and `start` tutorial events.
- `src/js/movement.js`:
  - Dispatch `gem_found`, `low_fuel`, `at_base`, and `hard_rock` tutorial events during mining/movement operations.
- `src/js/stats.js`:
  - Increase achievement toast duration from 3200ms to 5000ms.

## Implementation Steps
1. Write the plan to a `plan.md` file.
2. Update `adr/roadmap.md` with the new onboarding & QoL features under Phase C.
3. Update `index.html` to include the `#tutorial-hint` UI and the new `quit-btn` in the Game Over overlay.
4. Create `src/js/tutorial.js` to handle contextual hints using `localStorage` to avoid repeating hints.
5. Update `src/js/stats.js` to change the timeout from `3200` to `5000` for achievement toasts.
6. Update `src/js/main.js` and `src/js/movement.js` to dispatch tutorial events. Add "Quit to Menu" logic to `main.js`.
7. Verify all features work correctly by running `npm run lint` and all unit/integration tests (`npm test`).
8. Update `README.md` with the latest changes regarding the new onboarding.
9. Move the finished `plan.md` file to the `./adr` directory, timestamped (e.g., `YYYYMMDD_HH24mmss_plan_onboarding.md`).

## Technical Considerations
- The tutorial hints must not block gameplay or require explicit dismissal. They should automatically fade out after a few seconds or when the relevant condition is met.
- Ensure the "Quit to Menu" logic correctly resets the game state, unbinds unnecessary listeners, and binds proper event listeners for the "Press Start" screen.
- State for which tutorials have been seen needs to be robust, ideally saved in `localStorage`.

## Success Criteria
- New players receive timely, non-intrusive hints for key mechanics (moving, refueling, upgrading).
- Achievement toasts stay on screen long enough to read (5s).
- The Game Over screen provides an intuitive way to return to the boot screen.
- Lint and tests pass successfully.
