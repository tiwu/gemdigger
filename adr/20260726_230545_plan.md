# Plan: Expand Linting for CSS, HTML, and JSON

## Overview
We want to ensure code quality across all major file types in the project. Currently, we only have ESLint for JavaScript. We will add Stylelint for CSS, and use ESLint plugins to lint HTML and JSON files. This will provide a unified linting experience.

## Key Changes
- `package.json`: Add new devDependencies and update `lint` script.
- `eslint.config.js`: Add plugins for HTML and JSON linting.
- `.stylelintrc.json`: New configuration for CSS linting.
- `.clinerules`: Update to include linting compliance as a requirement.
- `README.md`: Document new linting commands.

## Technical Considerations
- Keep dependencies minimal to reduce security risk surface.
- Use standard configurations to avoid over-engineering.
- Ensure `eslint.config.js` (Flat Config) is compatible with the new plugins.

## Success Criteria
- `npm run lint` checks JS, CSS, HTML, and JSON.
- No linting errors in the codebase.
- `.clinerules` reflects the new linting requirements.
